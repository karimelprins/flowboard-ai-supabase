# FlowBoard AI — Full-Stack SaaS Dashboard

A full-stack SaaS admin dashboard built with Next.js, TypeScript, Supabase, and a modern dark AI-inspired UI.

## Live Demo

https://flowboard-ai-supabase.vercel.app/

## Features

- Real Supabase database integration
- CRUD operations for users, products, and orders
- Dynamic dashboard KPIs
- Revenue calculation from paid orders
- Stock risk detection
- Search and filters
- Details modals
- CSV export
- Loading and error states
- Responsive dark dashboard UI
- AI-style business insight section

## Tech Stack

- Next.js
- TypeScript
- React
- Supabase
- CSS
- Vercel
- Git & GitHub

## Database

The project uses three Supabase tables:

- users
- products
- orders

Dashboard numbers update based on real database records.
